# yuntai_part — 二维舵机云台拆解零件

智能小车项目的二维舵机云台（转盘旋转 + 肩部俯仰两自由度）拆解零件库，共 22 个 SolidWorks 单实体零件。

## 零件清单

| 分组 | 零件 |
|---|---|
| 云台底座 | 转盘舵机-转盘、转盘舵机-臂板、云台底板 1 / 2×2 / 3、云台舵机 ×2、云台舵盘 |
| 连接柱 | M3-30 铜柱 ×4、M3-22 铜柱 ×4 |
| 臂身 | 舵机 ×2、舵盘 ×2、U 支架、多功能支架 |

文件名前缀 `[N]` 为拆分时的实体编号，仅作区分用。

## 说明

- 零件为 STEP 中性格式导入后的单实体，无特征树。
- 用于 6 自由度桌面机械臂（底座转盘 + 肩部俯仰为此云台部分）的装配建模。
